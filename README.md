# nisehatakiti.online

WordPressテーマ・プラグインを、手軽な価格で提供するための小さなプロダクトストア。

## ブランドの位置付け

`hatakiti.com` が本格的なシステム開発・業務システム・SaaSなどを扱う表側のブランドであるのに対し、`nisehatakiti.online` はその「裏工場」的な位置付けとする。

nisehatakitiでは、特定の用途に絞ったWordPressテーマやプラグインなど、「あったらちょっと便利」を小さく作り、低い購入ハードルで提供する。

### 基本思想

> WordPressで、ちょっと便利なものを。

- 大規模なシステムではなく、小さく使える商品を作る
- 基本価格は **1,980円（税込）** を中心とする
- 「この値段なら試してみよう」と思える価格を重視する
- 商品は原則として買い切り型
- 安価でも品質・安全性・使いやすさは妥協しない
- 商品数を増やし、必要なものを単品で選べるストアを目指す

## 商品構成

```text
nisehatakiti.online
│
├── 同窓会
│   ├── Theme
│   └── Plugins
│       ├── 名簿管理
│       ├── 同窓会・同期会
│       └── その他
│
├── 舞台芸術
│   ├── Theme
│   └── Plugins
│       ├── 稽古管理
│       ├── チケット管理
│       └── その他
│
├── Portal
│   └── Portal Base
│
└── 今後追加する用途
```

基本は「用途 → 商品」という探し方を優先するが、全商品を横断して探せる「Products」も用意する。

商品は用途単位のセット販売も可能とするが、基本は小さな機能を単品で購入できることを重視する。

## Portal Baseの考え方

Portal Baseは、WordPressのユーザーアカウントを利用して、会員・利用者向けの小規模ポータル機能を提供する汎用プラグイン基盤とする。

想定する共通機能:

- ユーザー／アカウント管理
- ログイン・権限
- マイページ
- 全体向け・個人向けのお知らせ
- 申請・承認・差戻し
- 履歴

この基盤の上に、用途固有の機能を追加する。

```text
Portal Base
    │
    ├── Alumni
    │     └── 会員専用サイト・名簿等
    │
    ├── StageArt
    │     └── 団員向け機能・稽古等
    │
    └── その他の小規模団体向け機能
```

Alumniの会員専用サイトをPortal Baseの実証例として利用し、後から共通部分を汎用基盤として整理する。

## 商品ページの基本構成

Theme / Pluginごとに、購入判断に必要な情報を1ページにまとめる。

基本構成:

1. 商品名・短い説明
2. この商品でできること
3. 主な機能
4. 実際の画面・スクリーンショット
5. 各画面の使い方・操作説明
6. デモへのリンク
7. 動作環境・対応WordPressバージョン等
8. 価格（基本1,980円）
9. 購入ボタン

商品ページは「機能を詳しく説明するためのページ」であると同時に、「実際に使うイメージを持ってもらい、購入につなげるページ」とする。

### スクリーンショットを中心とした説明

商品説明は文章だけでなく、実際の管理画面・公開画面のスクリーンショットを中心に構成する。

商品制作時の標準フロー:

```text
Plugin / Theme完成
 ↓
機能を整理
 ↓
商品ページの説明構成を作成
 ↓
必要なスクリーンショットを指定
 ↓
実環境でスクリーンショット撮影
 ↓
画像を確認
 ↓
画像ごとの番号・キャプション・操作説明を作成
 ↓
商品ページ完成
```

## デモ

各Theme / Pluginには、可能な限り実際の動作を確認できるデモへの導線を設ける。

商品ページでは、購入ボタンとは別に明確な「デモを見る」導線を用意する。

## EC方針

EC基盤は可能な限り自前のWordPress環境に置き、月額固定費を増やさない。

初期構成の想定:

```text
WordPress
  + WooCommerce
  + Stripe等の決済サービス
  + nisehatakiti独自ストア機能
```

### 初期販売機能

まずは以下に絞る。

- 商品ページ
- カート
- 決済
- 購入者アカウント
- 注文履歴
- デジタル商品のダウンロード
- 購入後の自動案内

## WordPress製品の配布・ライセンス

商品数と販売数が増えた段階で、nisehatakiti独自のストア機能を拡張する。

```text
購入
 ↓
注文確定
 ↓
ライセンス発行
 ↓
購入者マイページ
 ↓
最新版ZIPダウンロード
```

将来的にはライセンスキー、1サイト認証、利用サイト登録、バージョン管理、WordPress管理画面からのアップデート通知・自動更新等を段階的に実装する。

## 価格方針

基本価格は **1,980円（税込）** を中心とする。

価格を低くすること自体を目的にするのではなく、購入前の心理的ハードルを下げ、「試してもらう」ことを重視する。

## サイトデザイン

nisehatakiti.onlineは企業サイトではなく、**小さなWordPress製品を生産して出荷する巨大な工場のストア**として設計する。

### ビジュアルコンセプト

- 巨大な工場の内部を正面から見た構図
- 左右ほぼ対称の設備・配管・歩廊で構成する
- 中央奥へ伸びる通路や設備によって強い奥行きを感じさせる
- 金属感は強すぎず、少し温かみのある工業イラスト／シネマティックな表現にする
- 工場の設備そのものが商品カテゴリーや導線を表現する
- 商品カードは工場の生産物・出荷物のように扱う
- 世界観は印象的にするが、商品情報・価格・購入導線は読みやすく保つ

### トップページの基本構成

```text
┌────────────────────────────────────┐
│ Header                             │
│ Nisehatakiti / 製品一覧 / デモ ... │
├────────────────────────────────────┤
│                                    │
│          巨大工場の正面             │
│                                    │
│   ┌────────┐   ┌────────┐          │
│   │ 同窓会 │   │ 舞台芸術│          │
│   └────────┘   └────────┘          │
│          ┌────────────┐             │
│          │ Nisehatakiti│             │
│          │ WordPress工場│             │
│          └────────────┘             │
│                                    │
│          ↓ 奥へ続く設備 ↓           │
│                                    │
├────────────────────────────────────┤
│ 新しい製品  [商品][商品][商品]       │
├────────────────────────────────────┤
│ 価格 / 使いやすさ / ドキュメント ... │
```

トップページは「工場を眺める」だけでなく、視線が中央奥へ進み、その先に商品が並んでいるように感じられる構成を基本とする。

## hatakiti.comとの役割分担

| | hatakiti.com | nisehatakiti.online |
|---|---|---|
| 位置付け | 本格的な開発ブランド | 小さなプロダクトストア／裏工場 |
| 主な商品 | システム・SaaS・個別開発 | WordPress Theme / Plugin |
| 価格感 | 案件・サービス単位 | 基本1,980円 |
| 販売形態 | 個別契約等 | オンライン購入・ダウンロード |
| 開発思想 | 大きな課題をシステム化 | 小さな不便を商品化 |

## 開発ロードマップ

### Phase 1: ストア基盤

- 専用WordPressテーマ
- 巨大工場をモチーフにしたトップページ

- 商品一覧・商品詳細ページ
- デモ導線

### Phase 2: 商品投入

- 同窓会向け商品
- 舞台芸術向け商品
- Portal Base

- 商品説明ページの標準化

### Phase 3: 共通基盤

- Alumniの会員専用サイトを実装
- Portal Baseとして共通部分を整理
- StageArt等への再利用を進める

### Phase 4: 製品管理

- 独自ライセンス管理
- バージョン管理
- 購入者向け最新版配布
- サイト単位のライセンス認証
- 自動アップデート

## 関連プロジェクト

- `nisehatakiti/alumni` — 同窓会向けWordPress Theme / Plugin

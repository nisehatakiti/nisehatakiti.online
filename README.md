# nisehatakiti.online

WordPressテーマ・プラグインを、手軽な価格で提供するための小さなプロダクトストア。

## ブランドの位置付け

`hatakiti.com` が本格的なシステム開発・業務システム・SaaSなどを扱う表側のブランドであるのに対し、`nisehatakiti.online` はその「裏サイト」的な位置付けとする。

nisehatakitiでは、特定の用途に絞ったWordPressテーマやプラグインなど、「あったらちょっと便利」を小さく作り、低い購入ハードルで提供する。

### 基本思想

> WordPressで、ちょっと便利なものを。

- 大規模なシステムではなく、小さく使える商品を作る
- 基本価格は **1,980円（税込）** を中心とする
- 「この値段なら試してみよう」と思える価格を重視する
- 商品は原則として買い切り型
- 安価でも品質・安全性・使いやすさは妥協しない
- 商品数を増やし、必要なものを単品で選べるストアを目指す

## 商品構成

商品は大きな用途カテゴリでまとめ、その中にThemeとPluginを配置する。

```text
nisehatakiti.online
│
├── 劇団
│   ├── Theme
│   │   └── 劇団Theme
│   └── Plugins
│       ├── 稽古管理
│       ├── チケット管理
│       └── その他
│
├── 同窓会
│   ├── Theme
│   └── Plugins
│       ├── 卒業期関連
│       ├── 役員紹介
│       └── その他
│
└── 今後追加する用途
    ├── Theme
    └── Plugins
```

基本は「用途 → 商品」という探し方を優先するが、全商品を横断して探せる「Products」も用意する。

商品は用途単位のセット販売も可能とするが、基本は小さな機能を単品で購入できることを重視する。

## 商品ページの基本構成

Theme / Pluginごとに、購入判断に必要な情報を1ページにまとめる。

基本構成:

1. 商品名・短い説明
2. この商品でできること
3. 主な機能
4. 実際の画面・スクリーンショット
5. 各画面の使い方・操作説明
6. デモへのリンク
7. 動作環境・対応WordPressバージョン等
8. 価格（基本1,980円）
9. 購入ボタン

商品ページは「機能を詳しく説明するためのページ」であると同時に、「実際に使うイメージを持ってもらい、購入につなげるページ」とする。

### スクリーンショットを中心とした説明

商品説明は文章だけでなく、実際の管理画面・公開画面のスクリーンショットを中心に構成する。

商品制作時の標準フロー:

```text
Plugin / Theme完成
 ↓
機能を整理
 ↓
商品ページの説明構成を作成
 ↓
必要なスクリーンショットを指定
 ↓
実環境でスクリーンショット撮影
 ↓
画像を確認
 ↓
画像ごとの番号・キャプション・操作説明を作成
 ↓
商品ページ完成
```

必要なスクリーンショットの指定と説明の大枠は、商品開発側で整理する。実際の製品画面の撮影は実環境で行い、その画像をもとに商品ページの解説を作成する。

必要に応じて、スクリーンショットに番号・注釈・矢印等を加え、初めて使う人にも理解しやすい説明にする。

## デモ

各Theme / Pluginには、可能な限り実際の動作を確認できるデモへの導線を設ける。

商品ページでは、購入ボタンとは別に明確な「デモを見る」導線を用意する。

デモは商品の種類に応じて、公開サイトの表示確認、管理画面の操作確認、またはその両方を提供する。

## EC方針

EC基盤は可能な限り自前のWordPress環境に置き、月額固定費を増やさない。

初期構成の想定:

```text
WordPress
  + WooCommerce
  + Stripe等の決済サービス
  + nisehatakiti独自ストア機能
```

### 初期販売機能

まずは以下に絞る。

- 商品ページ
- カート
- 決済
- 購入者アカウント
- 注文履歴
- デジタル商品のダウンロード
- 購入後の自動案内

決済サービスは月額固定費を避け、売上発生時の決済手数料のみを基本コストとする。

## WordPress製品の配布・ライセンス

商品数と販売数が増えた段階で、nisehatakiti独自のストア機能を拡張する。

```text
購入
 ↓
注文確定
 ↓
ライセンス発行
 ↓
購入者マイページ
 ↓
最新版ZIPダウンロード
```

将来的には以下を実装する。

- ライセンスキー発行・管理
- 1サイト単位のライセンス認証
- 利用サイトの登録・解除
- 商品バージョン管理
- WordPress管理画面からのアップデート通知
- WordPress標準アップデート機構に近い自動更新
- セット商品の複数ライセンス管理

ただし、これらを最初から実装せず、販売開始に必要な最小構成から段階的に追加する。

## 価格方針

基本価格は **1,980円（税込）** を中心とする。

価格を低くすること自体を目的にするのではなく、購入前の心理的ハードルを下げ、「試してもらう」ことを重視する。

例:

- 小規模Plugin: 1,980円
- Theme: 1,980円を基本価格とする
- 複数商品のセット: 必要に応じて割引価格

将来的に商品の規模によって例外価格を設定することは可能だが、最初は1,980円をブランド上の分かりやすい基準とする。

## サイトデザイン

nisehatakiti.onlineは企業サイトではなく、**小さなWordPress製品が並ぶストア**として設計する。

トップページでは会社説明を前面に出すのではなく、商品を探して購入することを最優先する。

優先順位:

1. nisehatakitiブランドの提示
2. 大カテゴリ（劇団・同窓会など）への導線
3. おすすめ商品・新着商品
4. 各商品の特徴・価格
5. デモ・詳細説明への導線
6. 購入導線
7. 最低限のブランド説明

### ロゴ

採用するロゴは、`Nisehatakiti` の筆記体風文字から始まり、最後の `i` から伸びた線が文字の周囲を一周して矢印になるデザイン。

「作ったものが次へ進んでいく」「気軽に次の商品へ進める」というブランドイメージに使用する。

## hatakiti.comとの役割分担

| | hatakiti.com | nisehatakiti.online |
|---|---|---|
| 位置付け | 本格的な開発ブランド | 小さなプロダクトストア |
| 主な商品 | システム・SaaS・個別開発 | WordPress Theme / Plugin |
| 価格感 | 案件・サービス単位 | 基本1,980円 |
| 販売形態 | 個別契約等 | オンライン購入・ダウンロード |
| 開発思想 | 大きな課題をシステム化 | 小さな不便を商品化 |
